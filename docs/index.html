What's New

Recent updates and feature additions in Bins for Windows 11.

v1.6.0 Cursor-Triggered Shelf Launcher
  • Introduced Shelf — a cursor-triggered launcher menu that pops open anywhere under your pointer via Middle-click / Mouse 4 / Mouse 5 (with optional Ctrl/Alt/Shift modifiers) or a global hotkey.
  • Choose between cascading vertical List mode (with hover submenus for Bins and live Folders) and compact Grid mode, with customizable Submenu, Top-level, and Bottom Bar placement.
v1.5.14 Instant Tooltip Suppression & Portable ZIP Releases
  • Upgraded Windows 11 taskbar tooltip & thumbnail suppression to event-driven hooks for instant, flicker-free flyouts and hover peeks.
  • Added Portable ZIP releases alongside the installer, with both artifacts automatically scanned by VirusTotal.
v1.5.13 Crisper Tile Spacing & VirusTotal Verification
  • Preserved a crisp 5 px minimum gutter between adjacent flyout tiles even at 0 px item padding, with tighter outer flyout margins.
  • Added automated VirusTotal scanning on every GitHub release with public scan reports included in release notes.
v1.5.12 Icon-Only Tiles & Taskbar-Centered Flyouts
  • Added an Item labels toggle per Bin to hide text labels inside the flyout for a clean icon-only grid.
  • Clicking a pinned Bin now centers the flyout directly above the pinned taskbar icon instead of the pointer location.
v1.5.11 What's New & Release History
  • Added a dedicated What's New sidebar view in Bins Manager with release-by-release feature highlights.
v1.5.10 Taskbar Picker & Faster Discovery
  • Added Add from Taskbar picker to import pinned and running taskbar apps and folders directly into a Bin.
  • Rebuilt the Start Menu & Store App Picker with UI virtualization, a 45s cache, and background async icon loading.
v1.5.9 Fluent Fanned-Stack Icon
  • Introduced the calm Windows 11 Fluent fanned-stack app icon with crisp high-DPI taskbar and tray rendering.
